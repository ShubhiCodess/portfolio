About me

Drawing fancy rectangles since 2016

My tech story started in 2006 when my dad brought home our first computer. It had Windows 98, a design so intuitive it never felt like learning — just exploring.

By 2016, I wasn't just using my phone, I was redesigning it. I'd rip apart the UI to make it feel more like me, because clunky design never sat right.

Before product design, I played around with photography, graphic design, and even VFX. But it all clicked when I started contributing to open-source Android projects. That's when I knew design felt like home.

Now I draw rectangles for a living. Some sharp, some round, some so bold they almost bounce off the screen. My toolkit? Systems thinking, empathy, and the occasional caffeine overdose.
